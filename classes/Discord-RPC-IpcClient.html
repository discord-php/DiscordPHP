IpcClient extends EventEmitter
in package
  • Application

FinalYes
IpcClient.php : 42

Optional local RPC facade, independent of the bot Gateway runtime.

connect() resolves only after READY. request() provides raw command envelopes, not typed support for every Discord RPC command. No payloads or tokens are logged. Events: ready(data, raw), dispatch(event, data, raw), error(Throwable), close(?CloseException), pong(bytes). Call close() to release owned resources.
